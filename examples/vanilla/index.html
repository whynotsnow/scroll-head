Vanilla demo

Headless scroll behavior with smooth CSS transitions.

Scroll down to hide and compact the header. Scroll up to reveal it. The core writes state; CSS owns the motion.

Motion belongs to CSS

The library updates attributes, variables, and optional classes. The demo imports the blog preset, then adds local layout styles for the page.

The compact height is driven by --scroll-head-height. Visibility is controlled by the state attribute or the synced class.

State changes are observable

The panel above is updated through onChange. The callback receives the current state, the previous state, and a map of fields that changed.

This makes it easy to connect the controller to analytics, custom classes, or framework state without making the package render any UI.

Enough content to scroll

Blog and product pages tend to need a small, predictable contract: top versus away, full versus compact, visible versus hidden. That is the shape this first version optimizes for.

Future framework adapters can reuse the same controller and keep their own lifecycle code thin.

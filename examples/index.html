scroll-head
Story Design Notes

Headless header behavior for calm content sites.

Scroll down to hide and compact the header. Scroll up to reveal it. The transition is pure CSS, driven by attributes and variables.

Story

This demo keeps the JavaScript deliberately small. The controller only tracks scroll position, direction, visibility, and size. The header's appearance stays in CSS.

That makes the library suitable for blogs, docs, and product pages where teams usually want their own markup and design system.

Design

The header switches from a full height to a compact height after the threshold. It also exposes a top or away edge state so CSS can move from transparent to elevated.

Small scroll movements are ignored by the hide and reveal deltas, which avoids flicker when the browser reports tiny wheel changes.

Notes

The same core can later support React, Vue, or Svelte wrappers because it has no rendering opinions. Framework adapters only need to own lifecycle and refs.
